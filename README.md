# johnhasson.com

Personal website for John Hasson — entrepreneur, software engineer, and investor.
Operated by Hawthorne LLC, the company behind [CoCallers](https://cocallers.com).

## Stack
Plain static HTML + CSS. No build step. Served via **GitHub Pages** from the
`master` branch of this repo, with the custom domain set in `CNAME`.

## Files
- `index.html` — home / about / expertise / projects / contact
- `privacy.html` — Privacy Policy (incl. SMS/A2P messaging terms)
- `terms.html` — Terms of Service
- `404.html` — not-found page
- `styles.css` — shared styles
- `CNAME` — custom domain binding (www.johnhasson.com)
- `.nojekyll` — disables Jekyll so files are served as-is

## Editing
Edit the HTML/CSS directly and push to `master`. GitHub Pages redeploys automatically.
